# snapshot خام

فایل‌های اصلی منابع را با نام snapshot و hash ذخیره کنید. فایل این پوشه نباید
دستی ویرایش شود؛ اصلاحات فقط در normalized انجام می‌شود.

snapshotهای فعلی شامل آزمون موتور/ملخ، سلول باتری، مدل برد مولتی‌روتور، ابزار
پردازش UIUC و فهرست ۱۵۹ مدل پرندهٔ OpenDroneList هستند. مقدار نرمال‌شدهٔ آخرین
فهرست با `pnpm data:aircraft` در `static/data/aircraft.v1.json` ساخته می‌شود.
