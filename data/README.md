# مخزن دادهٔ قابل ردیابی

این پوشه محل snapshot و بررسی منابع قطعات است. فایل‌های خام قبل از parse در
`raw/<source>/<snapshot>` نگه‌داری می‌شوند؛ دادهٔ بدون مجوز قطعی یا دارای خطا
به `quarantine/` می‌رود. فقط خروجی تأییدشده وارد `static/data` می‌شود.

هر رکورد و تصویر باید URL منبع، مجوز SPDX، زمان دریافت، SHA-256 و سطح کیفیت
داشته باشد. دانلود خودکار فقط برای منبعی مجاز است که حق بازتوزیع آن روشن باشد؛
در غیر این صورت اینجا فقط metadata و لینک منبع ثبت می‌شود.

ساختار دسته‌ها: `motors`, `props`, `escs`, `batteries`, `airframes`, `curves`
و `images/<category>`. manifest جمع‌آوری در `manifests/sources.v1.json` است.
