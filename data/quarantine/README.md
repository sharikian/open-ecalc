# قرنطینه

منابعی که مجوز بازتوزیع، provenance یا کیفیت فیزیکی آن‌ها تأیید نشده است اینجا
ثبت می‌شوند. این داده‌ها در bundle وب یا Tauri قرار نمی‌گیرند.

منابع فعلاً قرنطینه‌شده (جزئیات در `data/manifests/sources.v1.json`):

- `pythrust/` — مجوز هر رکورد upstream باید ممیزی شود.
- `uiuc-propeller-database/` — حق بازتوزیع اندازه‌گیری‌ها روشن نیست.
- `tyto-robotics/` — استفاده از دادهٔ benchmark نیازمند اجازهٔ کتبی است.
- `manufacturer-datasheets/` — دیتاشیت و تصویر محصولات بدون اجازه bundle نمی‌شوند.
