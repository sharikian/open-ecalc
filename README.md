# Open eCalc

ماشین‌حساب آفلاین مأموریت و سامانهٔ پیشران پهپاد برای وب، Windows و Android.

این پروژه کد یا بانک قطعات eCalc را کپی نمی‌کند. مدل‌ها، داده‌ها و فرض‌های هر
محاسبه در مخزن مستند می‌شوند و هر رکورد داده باید منبع و مجوز روشن داشته باشد.

مجوز کد: MIT

فهرست مدل‌های پرنده در `static/data/aircraft.v1.json` قرار دارد و از snapshot
اوپن‌دِرون‌لیست ساخته می‌شود؛ پروفایل‌های Mavic 2 Pro و Mavic 3 با نشانی رسمی
DJI ثبت شده‌اند. برای بازسازی داده، `pnpm data:aircraft` را اجرا کنید.
